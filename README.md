# QDII Monitor — QDII 基金与美股情绪监控台

**QDII Monitor** 是一个面向个人与小圈子投资者的轻量级 QDII 基金与美股市场监控平台。项目基于 **Cloudflare Pages + Pages Functions + KV** 构建，无需传统服务器，即可实现美股情绪指标追踪、场外 QDII 申购额度监控、场内 ETF 溢价预警、个性化 Bark 推送以及基于 Passkey（通行密钥）的账号管理。

---

## 核心功能

### 1. 大盘概览与市场情绪
* **核心指数与回撤监控**：追踪纳斯达克 100、标普 500 指数走势与年度动态回撤图谱（内置 `-10%` / `-20%` 关键参考线）。
* **情绪与估值温度**：集成 CBOE 波动率指数（VIX）、CNN 恐慌贪婪指数与历史 PE 高位表现分析。
* **极速首屏体验**：Chart.js 接入国内直连镜像并配备自动回退兜底；首屏优先渲染核心指标与主图，次级图表在浏览器空闲或切换标签页时按需绘制。

### 2. 场外 QDII 与场内 ETF 监控
* **多维度基金列表**：覆盖纳指基金、标普基金与场内 ETF，清晰展示代销额度、直销额度、近 1 年收益、昨日涨跌、基金规模、运作费率、首年成本及场内溢价率。
* **智能快捷筛选**：提供「今日可买参考」提示条，支持一键筛选 `额度 >= 1,000 元` 基金及 `低溢价/折价 (<1%)` 场内 ETF。
* **全端多字段排序**：桌面端与手机端均支持按任意核心指标升降序切换，点击基金代码即可一键复制。
* **移动端深度适配**：场内 ETF 与场外基金在手机端支持「精简视图 / 详细视图」自由切换（场内 ETF 默认精简视图）；全站采用纯矢量 SVG 图标，兼容深色 / 浅色主题切换。

### 3. 独立个人中心与云端同步
点击右上角用户名即可进入独立个人中心（桌面端左侧固定导航栏，移动端自适应顶部标签栏，支持 URL Hash 路由记忆，刷新页面保持当前位置）：
* **收藏夹**：集中管理已收藏的场外基金与场内 ETF，支持跨设备云端同步。
* **BARK 推送管理**：
  * 支持配置个人 Bark 推送地址，并提供一键测试推送。
  * 拆分为 **基金额度变化提醒**、**场内 ETF 高溢价预警**、**美股收盘复盘与情绪** 三个独立通道。
  * 每个通道均可独立设置开关、推送时间（北京时间）与自定义推送模板（支持一键恢复默认模板）。
* **登录与安全**：
  * **通行密钥（WebAuthn / Passkey）**：支持 ES256 设备密钥免密登录，完整展示已绑定密钥的备注名称、添加时间与最新使用时间，支持随时新增与删除。
  * **账号安全**：支持修改登录密码与绑定邮箱，并预留 GitHub / Google 第三方账号绑定入口。

### 4. 超级管理员与一次性邀请码体系
* **一次性核销机制**：新用户注册必须校验邀请码，注册成功后自动核销并记录使用账号与时间，防止邀请码被重复滥用。
* **邀请码管理（仅超管可见）**：超级管理员账号（默认 `Lesun`）在「设置 -> 邀请码管理」中可进行手动添加、自定义前缀批量随机生成、文本或 `.txt`/`.csv` 文件批量导入、一键导出 CSV 使用记录、快捷复制未使用邀请码以及删除作废操作。后端接口严格校验管理员权限，普通账号无权访问。

## 部署与配置指南

### 1. 部署到 Cloudflare Pages
1. 将本仓库推送至你的 GitHub 仓库。
2. 登录 Cloudflare 控制台，进入 **Workers 和 Pages -> 创建应用程序 -> Pages -> 连接到 Git**。
3. 选择本仓库，保持构建命令为空，构建输出目录设为 `/`（根目录），点击保存并部署。

### 2. 绑定 KV 命名空间
1. 在 Cloudflare 控制台左侧进入 **存储和数据库 -> KV**，创建一个新的命名空间（例如 `QDII_AUTH_KV`）。
2. 进入你的 Pages 项目 -> **设置（Settings）-> 绑定（Bindings）**，添加 KV 命名空间绑定：
   * **变量名称（Variable name）**：`AUTH_KV`（必须完全一致）
   * **KV 命名空间**：选择刚创建的命名空间

### 3. 配置环境变量
在 Pages 项目的 **设置 -> 环境变量（Environment variables）** 中按需配置以下变量（配置后需重新部署生效）：

| 变量名 | 是否必填 | 说明 |
| :--- | :---: | :--- |
| `JWT_SECRET` | **强烈建议** | 用于签发和校验用户登录态 Token 的随机强密钥 |
| `ADMIN_USERS` | 可选 | 超级管理员用户名列表（逗号分隔，默认已包含 `Lesun`） |
| `INVITE_CODES` | 可选 | 初始一次性邀请码列表（逗号分隔），首次加载后会自动同步到超管邀请码管理面板 |

### 4. 配置边缘缓存规则（可选，推荐）
为降低国内访问 `/data/*.json` 的回源延迟，可在 Cloudflare 域名控制台进入 **规则（Rules）-> 缓存规则（Cache Rules）** 新建规则：
* **匹配条件**：`URI 完整` `通配符` `https://你的域名/data/*.json`
* **缓存资格**：符合缓存条件
* **边缘 TTL**：忽略缓存控制标头，使用此 TTL -> `3600` 秒（1 小时）
* **缓存密钥（可选）**：勾选「忽略查询字符串」以提升边缘缓存命中率

### 5. 数据自动更新与推送
通过 GitHub Actions 或定时任务运行 `scripts/fetch_funds.py`，定期抓取最新基金额度、场内 ETF 溢价及美股情绪数据并提交至 `data/` 目录，同时按配置触发 Bark 推送通知。
